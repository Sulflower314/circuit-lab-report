# LaTeX 与图形

## 排版

模板 A4、四边 2.5 cm、中文小四、适中行距，页脚居中页码。ctex 自动选择字体，不写死 macOS 字体；字体、负号、希腊字母和上下标要检查缺字。`main.tex` 管入口，`labstyle.sty` 管样式。

编译工作目录固定为 `paper/`，所有输入路径按此解释，不是按被输入章节的目录。`\graphicspath{{../figures/}{./}}` 后可用图文件名。图用 `figure[htbp]`，必要时 `\FloatBarrier`，不全用 `[H]` 制造空白。图题下、表题上，标签放 caption 后，用 ref/eqref 自动引用。

placeins 为可选依赖，缺失时模板中的 FloatBarrier 只结束段落；应通过实际 PDF 检查浮动位置，需要强制排空时在合理位置用内置 clearpage。核对正文结束标记后是否还有浮动图表页，必要时人工更正正文页数记录。

表格用 booktabs，宽表 tabularx、跨页 longtable，不整体缩成小字。siunitx 统一单位，如 `\qty{1.00}{\kilo\ohm}`。模板需 siunitx v3；旧版可核实后适配 SI/si。变量斜体、单位正体，长公式用 align/split 分行。

## 电路图

默认不重画。优先使用用户提供的现成图、手绘扫描或与实际实验相符的讲义原图。确认来源、对应实验及参数版本，保留原件，另存必要的裁切/旋转副本。裁切不能丢掉端口、连接点、参考方向、元件参数和解释电路所需的信息；不擅自补线、改值或替换符号。手写图保持原貌，字太小或接线模糊时先核对。

PDF 原图可保留矢量方式裁出单图；扫描图用足够清晰的原尺寸插入，不反复压缩。图注标明资料及页码或“实验手绘电路图”。使用原图不要求额外制作 CircuitikZ 源码。

只有用户要求或现有图确实无法辨认/用于排版时才考虑重绘。可选 CircuitikZ，符号风格统一；`assets/circuit-example.tex` 仅为工具演示。先列节点/支路，再放元件、参数、参考方向、连接点和仪器，编译后对照原图。交叉与连接区分，箭头约定与方程一致。复杂元件查本机官方文档，不猜语法。只有实际用到重绘时才在报告入口加载 `\usepackage{circuitikz}`。流程或设备关系图确有需要才用 TikZ/DrawIO。

## 数据图

基础工具只画 CSV 已有列，不生成理论或拟合值：

```text
python <SKILL_DIR>/scripts/plot_measurements.py data/measurements.csv --x voltage_V --y current_mA --xlabel "电压 / V" --ylabel "电流 / mA" --output figures/vi
```

已有理论列加 `--theory theoretical_mA`，已知不确定度列加 `--yerr u_current_mA`，对数横轴加 `--logx`。默认实测点、理论线，`--connect` 按原行顺序连接实测，仅用于顺序具有物理意义时。理论按 x 排序连接，多工况先分表，避免误连。

输出 PDF、300 dpi PNG 和输入哈希/参数 `.meta.json`。空值、NaN、无穷、负不确定度或对数轴非正值会报错，不会静默跳过。复杂拟合与幅相双图另写项目脚本。

白底、单位明确、线型和标记可灰度区分；稀疏点不平滑伪装密集测量。按最终插图尺寸检查字号。每张图有用途，不为凑页增加重复图。

## 照片与验证

保留原图，裁切副本关联来源。不能删除影响解释的量程、时基、倍率和通道信息，必要时图注说明。相近波形可拼版并标 (a)/(b)。不得改读数、擦异常或把理想重绘图当实测。

先核数值和接线，再检查日志中的未定义引用、缺字、Overfull hbox/vbox。检查脚本只支持普通字面量 input/include，不是完整 TeX 解析器，自定义宏及复杂教师模板须人工核对。

每页渲染查看，编译成功不能替代视觉验收。模板草稿很短属预期，不能复制占位段落凑到 15 页。PDF 检查缺工具时写明未执行，不报全部通过。
