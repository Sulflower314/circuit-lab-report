# 八章写作与篇幅

## 页数预算

约 18 页的起始分配如下，按项目和材料调整，不逐章强制换页：

| 章节 | 约占页数 | 重点 |
| --- | --- | --- |
| 实验目的 | 0.5 | 可验证的知识与操作目标 |
| 实验原理及电路图 | 3.5 | 必要推导、测量方法和电路 |
| 实验仪表设备 | 0.5 | 设备表及测量设定 |
| 实验内容及步骤 | 2 | 分项目操作、工况和记录量 |
| 实验结果 | 5 | 数据表、波形、曲线和计算 |
| 实验结果分析 | 3.5 | 定量比较、物理解释和局限 |
| 思考题 | 2 | 原题、推导和结论 |
| 实验心得 | 1 | 真实收获与改进 |

超长时合并相似波形、删除重复照片和推导，保留关键数据与分析。太短时检查是否漏指导书要求、必要推导、单位、条件或原题，仍不足则保留真实短稿。不能为了页数堆教材知识。

## 各章要求

1. **实验目的**：简短条目说明理解、验证和掌握什么，对应实际项目，不提前宣称成功。
2. **实验原理及电路图**：按物理定律→电路方程→预测关系→测量量展开。符号首次解释含义、单位及方向，说明理想假设。优先插入用户现成/手绘图或讲义原图，不默认重绘。核对各接线状态的电源、元件参数、仪器位置和参考方向；原图信息缺失在正文简短说明已知条件，关键歧义先询问，不猜数值或改图。
3. **实验仪表设备**：表列名称、型号、数量及已知量程/设定、精度。无来源的字段可不设；分辨率不等于准确度；铭牌不证明本次使用的设定。
4. **实验内容及步骤**：按实验项目分二级标题，写接线依据、输入、仪器设定、调节、测量和记录。区分指导书规定、已确认实际操作与预习计划。仅加入与当前接线相关的注意事项，不虚构已执行步骤。
5. **实验结果**：先交代工况和单位，再给实测、理论、仿真和计算表；保留对应关系。展示代表性计算。波形图注写已确认的通道、时基、幅值、倍率和工况，未知不补造。图前说明问题，图后描述观察结果，充分原因分析放第六章。
6. **实验结果分析**：按结果章同序，写理论预期→具体数值比较→偏差方向及大小→原因证据→尚不能确认的因素。不能仅凭接近就声称验证，也不能自行设统一合格阈值。无仪表规格/不确定度时不写“处于允许误差内”。讨论容差、源内阻、负载效应、频率响应或接触电阻时解释影响方向，能估算则给量级，缺依据就说明是可能原因。
7. **思考题**：保留原题和编号，逐题给依据、推导、结论；引用本次结果。原题未给保持草稿缺项，不用自拟通用题代替。
8. **实验心得**：依据用户经历、困难和改进写作，不虚构接错线、调试、分工或重测次数。无经历时先询问；基于材料的知识收获可暂拟，但标记待确认，不冒充已确认的第一人称经历。

目的、设备和步骤适合列表，原理和分析用连贯段落。少用“充分验证”“深刻认识”等套话，以哪个数据支持哪个结论来表达。引用仅列实际使用的可核验来源。

## 正文语言

以学生实验报告的口吻直接陈述原理、操作、数据和判断，减少防御性措辞、AI 自述和解释写作过程的语言。

- 不写“作为 AI”“根据你提供的材料，我将”“我无法亲自操作”“本段旨在”“为了避免误导”“仅供参考”等与实验论证无关的话。
- 不反复提醒“无法确认”“不能保证”“不应过度解读”，不在每段附限制声明。确实影响结论的限制在对应位置一次讲清，例如“未测量电源内阻，计算采用理想电压源模型”。
- 不叙述资料整理、绘图和报告生成过程；“读取图片后识别出”“使用脚本得到”改写为实验量与结果本身。具体处理方法若影响结果则保留，例如“对 100—1000 Hz 数据作对数坐标插值”。
- 不以“需要指出的是”“值得注意的是”“综上所述”等套语代替具体联系，避免“不是……而是……”的无必要辩解。
- 数据支持时直接说清结论；不支持时缩小结论范围或给出具体条件。减少赘述不能变成隐瞒缺测、把推测写成事实或把仿真写成实测。
- 缺项、工具限制和待用户核对事项集中在工作记录与交付说明；草稿正文只保留必要的简短缺项，最终版不保留这些提示。

例如，“由于无法获知所有实际因素，因此不能保证误差分析完全准确”应删去；如确需说明，改为“电阻未单独实测，理论值按标称阻值计算”。“根据提供的数据可以看出，实验结果基本符合预期”改为有依据的具体比较，如“输出电压随负载电阻增大而上升”，并在实际报告中结合相应数值。
